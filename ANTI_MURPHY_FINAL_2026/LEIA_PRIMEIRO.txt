WINDOWS:
1. Extraia esta pasta do ZIP para um local de sua preferência.
2. Execute INICIAR_ANTI_MURPHY.bat com dois cliques.
3. O aplicativo deve abrir no navegador padrão. Mantenha a janela do servidor aberta.
4. Se não abrir automaticamente, use o endereço local que aparecer na janela.

Necessário Python 3.10 ou mais recente. Não é necessário instalar npm ou Streamlit para a interface principal.
