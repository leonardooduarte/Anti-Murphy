# Verificações da versão

## Verificado neste ambiente
- Parse das unidades de código Python alteradas.
- Sintaxe do JavaScript embutido no HTML.
- 121 testes Python selecionados aprovados, preservando simulação,
  contratos, exportação e ferramentas anteriores.
- Replay HTML autocontido em Chromium a 1366×768, 1440×900 e 1920×1080.
- Sem exceções JS nos três tamanhos.
- Controle do tempo até o incidente e mudança A/B.
- Ausência de extrapolação horizontal nas resoluções testadas.
- Um único arquivo .bat de entrada na raiz.

## Não verificado
- Execução do Streamlit no Windows.
- Compatibilidade exata com a versão Python instalada pelo usuário.
- FPS sustentado em hardware do usuário.
- Homologação de competências, buffers finitos e setups dependentes da sequência.

## Natureza dos resultados
O exemplo tem cinco postos e foi calculado no motor V30.2. Os cenários
contêm dados sintéticos. A alternativa utiliza uma redução hipotética
de tempo de reparo e não incorpora o investimento da manutenção.
O software não executa comandos em máquinas reais.

## Observações de qualidade
As alterações mais profundas nesta rodada foram de hierarquia visual,
linguagem e navegação. Os módulos industriais avançados foram
preservados, sem alteração de seus cálculos centrais.
