# Anti-Murphy — AM19 sobre Evolução Visual 02

Extraia em pasta nova e execute `INICIAR_ANTI_MURPHY.bat`.
O alvo é `start.py`, servidor web local em `atelier`. A evolução visual recebida
foi preservada. Não é necessário aplicar o patch se baixou o ZIP completo.

As cinco falhas anteriores da regressão foram resolvidas com contratos
funcionais e duas prévias offline restauradas. As prévias são demonstrações
estáticas com dados fixos; não são o projeto ativo nem registram decisões.
Leia ENTRADAS_AM19_2026.md para distinguir o aplicativo principal das
interfaces e ferramentas históricas adicionais, inclusive seus limites.

Preserve a instalação anterior e faça backup dos projetos locais antes de
qualquer migração. Nenhum projeto ou registro histórico foi modificado nesta
etapa. Windows, BAT e projetor precisam de validação nativa no seu computador;
a verificação desta entrega foi realizada no Linux/Python 3.12.
