## Baixar e executar

- Para o aplicativo pronto, abra ENTREGAS/ANTI_MURPHY_AM11_COMPLETO_2026.zip e use o botão de download do GitHub.
- Para tudo desta branch: Code → Download ZIP. Extraia em pasta nova.
- Abra ANTI_MURPHY_FINAL_2026/INICIAR_ANTI_MURPHY.bat no Windows com Python3.10+.
- Preserve sua instalação anterior e seus projetos locais. O pacote usa o workspace arquivado da base, não dados de outra instalação.
